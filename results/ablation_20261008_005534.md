## 结论

- BM25 单独达到 Hit@1 85% / MRR 0.917，优于纯向量的 82% / 0.899——技术文档场景下词面匹配本身就是很强的信号，而单靠向量会漏掉精确的 API 名与参数名。
- RRF 融合把 MRR 从 0.899 提到 0.939（+0.040），说明两路召回确实互补。
- Cross-Encoder 精排后 MRR 达 1.000（较融合前 0.939 提升 0.061），代价是延迟 P95 从 652.8ms 升到 653.5ms——典型的「用延迟换准确率」。
- Hit@5 在四档方案里全部 100%，已饱和（语料仅 32 chunk，Top-5 覆盖 15.6%），故改用 Hit@1 与 MRR 作为区分指标。
- **拒答是独立于检索的另一个问题**：四档方案的拒答率都没到 100%，说明语料里根本没有的内容仍会被自信地当成答案。这需要更高阈值 / 答案自检 / 检索覆盖率校验，而不是继续调检索算法。
